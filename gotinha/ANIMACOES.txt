PINGO — 23 ANIMAÇÕES

Três refinadas:
1. Andar: apoio mais longo, patinhas alternadas, braços em contrapeso e inversão de direção suave.
2. Dormir: corpo acomodado, respiração lenta e três letras Z em geometria 3D subindo e desaparecendo.
3. Comer: aproximação do biscoito, pausa de mastigação, pequenas contrações e farelinhos.

Vinte novas:
Dar tchau; dançar; dar uma voltinha; pular de alegria; espreguiçar; bocejar; ficar tristinho; ficar emburrado; levar um susto; dar risada; pensar; olhar curioso; comemorar; se concentrar; tomar água; brincar com bola; ficar tímido; chamar atenção; ficar cansado; sentir orgulho.

index.html: seletor das 23 animações. Desative a opção de movimentos espontâneos para manter o estado escolhido.
passeio.html: botão para ativar o modo flutuante de passeio pela tela inteira, com mini painel.
favorito.txt: URL javascript para um favorito do Chrome. O script é carregado do repositório Meus-Scripts. Também há um botão arrastável em passeio.html.

O mascote anda em todas as direções da área visível da aba. Você pode arrastá-lo, ajustar a velocidade, pausar, remover e selecionar as 23 animações no mini painel. O passeio fica limitado às bordas e à aba onde foi ativado. Não acompanha a mudança de página ou aba automaticamente. Páginas internas do navegador e páginas com políticas restritivas podem bloquear o favorito.

pingo-23-animacoes.glb contém as 23 pistas de animação nomeadas (clips), compartilhando a mesma geometria. Reproduza um clip por vez. O catálogo animacoes.json lista todos os clips. Há também arquivos individuais para andando, dormindo e comendo, além do modelo principal pingo.glb.

Os cinco GLBs passaram pelo validador glTF com zero erros e zero avisos. O pacote foi carregado pelo GLTFLoader, as 23 animações foram exercitadas com matrizes finitas e ciclos que fecham. As três principais foram conferidas no visualizador HTTPS. A página publicada em GitHub Pages foi usada para testar a ativação, o mini painel, as trocas de animação e os cliques na página. O favorito continua sujeito às políticas da página de destino.

Para reconstruir: npm install; npm run build. Para gerar o pacote e os três estados: npm run animations. Para gerar a apresentação principal: npm run export. Os arquivos .cjs gerados são auxiliares de construção.
