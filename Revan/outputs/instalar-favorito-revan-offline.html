Favorito do minidashboard Revan

Arraste o botão abaixo para a barra de favoritos do Chrome ou Edge.

💠 Revan — Equipamentos

Segure o botão acima e solte na barra de favoritos do navegador.

  1. Ative a barra de favoritos com Ctrl + Shift + B.
  2. Arraste o botão azul para a barra.
  3. Abra um atendimento no Revan e clique no favorito criado.

Se preferir, importe revan-favoritos.html no gerenciador de favoritos do navegador e mova o favorito para a barra.

Versão 4.17.1. Este favorito contém o código completo e não busca atualizações remotas. Arraste um novo favorito após cada atualização. Inicia como botão.
