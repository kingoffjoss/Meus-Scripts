01   Salve nos favoritos

Arraste o botão abaixo para a barra de favoritos do Chrome ou Edge no computador.

↗ Vídeo flutuante Mostre a barra com Ctrl + Shift + B. Clique no favorito em qualquer página para ativar o painel dentro dela. Se houver um vídeo, ele será enquadrado automaticamente.
Instalação manual

Crie um favorito com o nome “Vídeo flutuante” e cole o código abaixo no campo URL/endereço.

02   Escolha o que assistir

Ative o favorito na página em que quer manter o painel. Use o botão “Link” do painel para colar o endereço de um vídeo de outra aba.

O painel aceita links YouTube, Vimeo e arquivos MP4/WebM. A barra aparece ao passar o mouse; o restante é só o vídeo.

Enquadra só o vídeo

Passe o mouse sobre o painel para revelar a barra. Arraste por ela para mover e puxe qualquer borda para redimensionar. O painel acompanha a rolagem da página. O botão × fecha o painel e devolve o vídeo original ao lugar.

O favorito executa o código na aba atual, como pelo console. Ele não consegue capturar automaticamente vídeos de outras abas. Sites com políticas de segurança, DRM ou players isolados podem limitar o funcionamento. Um player incorporado pode reiniciar ao ser movido.

Executar pelo console do navegador

Copie este código e execute no console da página onde quer abrir o painel. O código é o mesmo usado pelo favorito.

Sem extensão, conta ou rastreamento. O favorito funciona na aba em que você clicar.
