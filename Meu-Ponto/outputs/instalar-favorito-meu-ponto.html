◷ Meu ponto

  1. Exiba a barra com Ctrl + Shift + B.
  2. Arraste o botão para a barra.
  3. Abra o Meu RH e clique no favorito.

O painel inicia pausado e em simulação, conforme o código enviado. Ativar o modo real e o agendamento são ações feitas por você no painel.

Carrega o código do seu GitHub via jsDelivr, como script externo, sem Function ou eval. O CDN pode manter cache das atualizações. Se o painel já estiver aberto, apenas reabre, preservando o agendamento. Para carregar mudanças, recarregue a página e clique novamente. O código usa o fuso do computador. Recarregar pausa o agendamento. Confira sempre a confirmação do Meu RH.
